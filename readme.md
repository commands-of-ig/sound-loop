# My Sound Loop

A simple website that continuously plays my chosen sound.

## Features

- Continuous audio looping
- Start and Stop controls
- Volume control
- Animated sound visualizer
- Mobile-friendly design
- No Firebase
- No database
- No paid storage
- Can be hosted using GitHub Pages
